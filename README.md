# TeachersDeck & LectureDeck for Moodle: published site

This repository holds only the built website served at https://teachersdeck.github.io/teachersdeck-moodle/, the app the
TeachersDeck Moodle plugin (`local_teachersdeck`) opens inside a course. It is the plugin's default app address.

The source is kept privately. Don't edit files here: each release replaces everything in the `site/` folder.
